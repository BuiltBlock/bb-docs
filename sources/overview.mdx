Sources are connected from **Settings**, on the **Sources** tab. Each source opens its own dialog.

| Source | Who connects it | What it adds |
| --- | --- | --- |
| [HubSpot](/sources/hubspot) | Admin | Companies you name, plus their contacts, deals, notes, emails, calls, and meetings |
| [Gong](/sources/gong) | Admin | Calls and transcripts on companies you already added |
| [Granola](/sources/granola) | Admin | Meeting notes and transcripts on companies you already added |
| [Gmail](/sources/gmail) | Admin | Mail on companies you already added, and send from Desk |
| [Slack](/sources/slack) | Admin | Messages from the public channels you choose |
| [Google Calendar](/sources/google-calendar) | Each member, for their own calendar | Meetings on companies you already added |

## Connected is not imported

A source shows as connected when BuiltBlock has permission to read it. Companies still have to be added. HubSpot is the place you add them. The other sources attach records to accounts that already exist.

If a connection fails or access is revoked, the dialog says to reconnect. Select **Reconnect** and sign in again.

**Confirm disconnect** stops new records from that source. Data already stored in BuiltBlock stays.
