---

Built Block lets you build and manage automated workflows through a clean REST API and Model Context Protocol (MCP) integrations. This guide walks you through creating an account, locating your API key, and running your first API requests so you can start building right away.

<Steps>

### Create your account

Navigate to [app.builtblock.com/signup](https://app.builtblock.com/signup) and fill in your name, email address, and a strong password. After you submit the form, check your inbox for a verification email and click the confirmation link. Once verified, you land on the Built Block dashboard and your account is ready to use.

<Note>
  If you don't see the confirmation email within a couple of minutes, check your spam folder. You can also request a new verification email from the sign-in page.
</Note>

### Get your API key

Every request you make to the Built Block API must be authenticated with a personal API key.

1. In the dashboard, click your avatar in the top-right corner and select **Settings**.
2. Open the **API Keys** tab.
3. Click **Generate new key**, give it a descriptive name (for example, `local-dev`), and click **Create**.
4. Copy the key immediately — Built Block only displays the full key once.

<Warning>
  Treat your API key like a password. Never commit it to source control or share it in public forums. If a key is ever exposed, rotate it immediately from the **API Keys** settings page.
</Warning>

### Make your first API call

With your key in hand, call the `GET /projects` endpoint to confirm everything is wired up correctly. Replace `YOUR_API_KEY` with the key you copied in the previous step.

<CodeGroup>

```bash curl
curl -X GET https://api.builtblock.com/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```javascript JavaScript (fetch)
const response = await fetch("https://api.builtblock.com/v1/projects", {
  method: "GET",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

A successful response returns a `200 OK` status and a JSON array of your projects (empty for a brand-new account):

```json
{
  "data": [],
  "meta": {
    "total": 0,
    "page": 1,
    "per_page": 20
  }
}
```

<Tip>
  If you receive a `401 Unauthorized` error, double-check that you copied the full API key and that the `Authorization` header value starts with `Bearer ` (note the trailing space).
</Tip>

### Create your first project

Projects are the top-level containers for your workflows. Send a `POST /projects` request with a name and an optional description to create one.

<CodeGroup>

```bash curl
curl -X POST https://api.builtblock.com/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My First Project",
    "description": "Exploring Built Block workflows"
  }'
```

```javascript JavaScript (fetch)
const response = await fetch("https://api.builtblock.com/v1/projects", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "My First Project",
    description: "Exploring Built Block workflows",
  }),
});

const project = await response.json();
console.log(project);
```

</CodeGroup>

A `201 Created` response confirms the project was created and returns the new project object:

```json
{
  "data": {
    "id": "proj_01hx3k9mz4fg8vtqbe2nrwc7ys",
    "name": "My First Project",
    "description": "Exploring Built Block workflows",
    "created_at": "2024-05-10T14:23:00Z",
    "updated_at": "2024-05-10T14:23:00Z"
  }
}
```

Save the `id` value — you'll reference it when creating workflows inside the project.

</Steps>
