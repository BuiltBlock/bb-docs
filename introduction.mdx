Whether you're automating business processes through the dashboard or integrating programmatically via the API, Built Block adapts to how you work.

## What You Can Do with Built Block

Built Block covers three main capability areas:

**Platform** — Use the dashboard to create projects, configure integrations, and manage your team's settings without writing any code.

**API** — Call the REST API to create and manage projects, trigger workflows, and retrieve data programmatically from your own applications.

**MCP** — Connect popular AI assistants (Claude, Cursor, VS Code, and others) to Built Block so they can query and act on your platform data using natural language.
