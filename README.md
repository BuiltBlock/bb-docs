# BuiltBlock docs

Customer documentation for BuiltBlock, published with Mintlify.

## Preview

Install the [Mintlify CLI](https://www.npmjs.com/package/mint):

```bash
npm i -g mint
```

From this directory, where `docs.json` lives:

```bash
mint dev
```

Open `http://localhost:3000`.

## Check

```bash
mint validate
mint broken-links
```

The Account API pages are generated from `openapi.json`.
