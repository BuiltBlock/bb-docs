The Built Block MCP server brings your workspace data and workflow automation directly into the AI tools you already use. Instead of switching between your AI assistant and the Built Block dashboard, you can ask your AI to list projects, trigger webhooks, inspect integrations, and more — all from within a single conversation.

## What is MCP?

The Model Context Protocol (MCP) is an open standard that gives AI assistants a structured way to connect to external data sources and tools. Think of it as a universal plugin layer: once you point an MCP-compatible client at an MCP server, the AI can read data from that server and call actions on it, right inside the chat interface. Built Block ships a fully hosted MCP server at `https://mcp.builtblock.com` so you do not need to run any infrastructure yourself.

## What the Built Block MCP Server Enables

With the Built Block MCP server connected to your AI assistant, you can:

- **Query your workspace** — ask the AI to list all projects or pull up the details of a specific integration without leaving your editor
- **Automate from natural language** — instruct the AI to create a project or fire a webhook as part of a larger task
- **Reduce context-switching** — keep your entire workflow automation layer accessible inside Claude, Cursor, or VS Code
- **Build faster** — let the AI read live resource data from your workspace to generate accurate code, configs, or documentation

<Note>
  The Built Block MCP server uses your API key for authentication. Treat it with the same care as any other secret — never commit it to version control.
</Note>

## Supported AI Clients

Built Block's MCP server works with any MCP-compatible client. The following clients are tested and supported:

| Client | Notes |
|---|---|
| **Claude Desktop** | Full tool and resource support via `claude_desktop_config.json` |
| **Cursor** | Configure via `.cursor/mcp.json` in your project root |
| **VS Code with Copilot** | Add the MCP server block to your VS Code `settings.json` |
| **Continue.dev** | Add as a custom MCP provider in `~/.continue/config.json` |
