The BuiltBlock MCP server lets Claude, ChatGPT, Cursor, or your own client ask about your customer model. Sign in with your BuiltBlock account. You do not create an API key for MCP.

Server URL:

```text
https://mcp.builtblock.com/mcp
```

The same questions are available from **New chat** in the app. See [Ask questions](/product/explore).

## Tools

| Tool | Who can use it | What it does |
| --- | --- | --- |
| [`ask`](/mcp/ask) | Anyone signed in | Ask about a customer, or find a pattern across companies |
| [`run_account`](/mcp/run-account) | Admins | Add a company by name or domain. Processing continues in the background |
| [`intake`](/mcp/intake) | Admins | Add a note, email, or transcript to the customer context |

`ask` returns a session. Pass that session on follow-up questions in the same investigation. Omit it when you start a new question.

Adding a company returns when the work is queued. It does not mean the account is ready.
