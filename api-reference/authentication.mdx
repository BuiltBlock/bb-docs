Account API requests use an API key for your organization. Create and revoke keys in the app.

<Steps>
  <Step title="Open the API page">
    In [app.builtblock.com](https://app.builtblock.com), open the account menu and choose **API**.
  </Step>
  <Step title="Create a key">
    Select **API key**. An admin can create and revoke organization keys. If you are not an admin, the page says to ask an admin.
  </Step>
  <Step title="Send the key">
    Send the key on every request to `https://api.builtblock.com`.
  </Step>
</Steps>

```bash
curl "https://api.builtblock.com/v1/accounts" \
  -H "Authorization: Bearer $BUILTBLOCK_API_KEY"
```

`x-api-key` is also accepted.

```bash
curl "https://api.builtblock.com/v1/accounts" \
  -H "x-api-key: $BUILTBLOCK_API_KEY"
```

<Warning>
  Treat the key like a password. Do not put it in browser code or a public repository. Revoke it from the **API** page if it leaks.
</Warning>

## Limits

Each organization can make 60 requests per minute and 10,000 requests per day. A request over the limit returns `429` with a `Retry-After` header. See [Errors](/api-reference/errors).

## What this key is not

The API key is only for `https://api.builtblock.com`. [MCP](/mcp/connect) uses sign-in to your BuiltBlock account. The key does not work on the MCP server, and a signed-in app session does not work on `/v1`.
