The Users API provides a single endpoint that returns the profile of the user associated with the API key in your request. Use this endpoint to confirm which account your key belongs to, verify that it has the expected role and permissions, and display user details in your own tooling.

---

## Get the current user

Retrieve the profile of the authenticated user. No path or query parameters are required — Built Block derives the identity from your API key automatically.

**`GET /users/me`**

### Response fields

<ResponseField name="id" type="string" required>
  Unique identifier for the user account.
</ResponseField>

<ResponseField name="email" type="string" required>
  Email address associated with the account.
</ResponseField>

<ResponseField name="name" type="string" required>
  Full display name of the user.
</ResponseField>

<ResponseField name="role" type="string" required>
  The user's permission level within the account. One of:

  - `owner` — full administrative access, including billing and account deletion.
  - `admin` — can manage projects, integrations, webhooks, and team members, but cannot access billing.
  - `member` — read/write access to projects and integrations; cannot manage team members or account settings.
</ResponseField>

<ResponseField name="created_at" type="string" required>
  ISO 8601 timestamp indicating when the user account was created.
</ResponseField>

<Note>
  This endpoint is the fastest way to validate an API key at startup. If the key is invalid or revoked, the request returns an HTTP `401 Unauthorized` response. If the key is valid but lacks the role your application requires, inspect the `role` field in the response and surface a clear error to your users.
</Note>

<CodeGroup>

```bash cURL
curl https://api.builtblock.com/v1/users/me \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript (fetch)
const response = await fetch("https://api.builtblock.com/v1/users/me", {
  method: "GET",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
});

if (!response.ok) {
  throw new Error(`Request failed with status ${response.status}`);
}

const user = await response.json();
console.log(`Authenticated as ${user.name} (${user.role})`);
```

</CodeGroup>
